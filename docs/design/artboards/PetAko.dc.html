Ako & kawanan

Teri dari logo yang jadi hidup: badan ramping, moncong menjorok, mata besar di depan, tutup insang, sirip punggung dan dubur, ekor bercabang dalam, dan celah gelap seperti di logo. Sudah dipasang di Dashboard, Asisten HP, tombol asisten mini, Beranda HP, Pengaturan, dan penyiapan pertama.

LautAko.svelte: latar bawah laut (sinar cahaya, gelembung, partikel, rumput laut, dasar pasir, kawanan jauh). Mengisi wadahnya; dasar laut selalu terlihat di wadah lebar maupun tinggi.

Aturan

  • •Mood hanya naik selama hari itu (habit dicentang, tugas selesai, streak bertambah). Tidak pernah turun di bawah biasa, dan Ako tidak menyindir saat kamu libur.
  • •"sad" hanya untuk error sistem: unduhan gagal, kunci API ditolak, sinkron gagal.
  • •Klik membangunkan Ako dari tidur. Semua animasi (CSS dan kawanan SMIL) berhenti saat jendela tersembunyi.
  • •prefers-reduced-motion atau motion="diam": gambar diam. FPS di bawah 20 → otomatis Diam (state "Ako beralih ke gambar diam").
  • •Tanpa WebGL, tanpa pustaka: SVG + CSS (±7 KB setelah gzip untuk 8 status), hanya transform dan opacity yang bergerak.
