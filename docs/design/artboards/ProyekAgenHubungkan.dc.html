Tambahkan server MCP di folder repo export ANCHOA_TOKEN=anc_… # simpan di keyring / .env lokal, jangan di-commit claude mcp add --transport http anchoa \ https://<ref>.supabase.co/functions/v1/agent-mcp \ --header "Authorization: Bearer ${ANCHOA_TOKEN}" --scope project Agen lain yang mendukung MCP (Cursor, Codex CLI, Gemini CLI, dll.) memakai URL dan token yang sama — cara menambahkannya ada di dokumentasi masing-masing.
3
Beri tahu agen kapan mencatat (tempel ke CLAUDE.md / AGENTS.md) ## Anchoa - Setelah membuat rencana: panggil anchoa.plan_create (langkah-langkahnya). - Saat mulai/selesai mengerjakan langkah: anchoa.task_update. - Setelah menjalankan tes: anchoa.test_report (lulus, gagal, nama tes gagal). - Jangan kirim isi file, rahasia, atau .env ke Anchoa.
4
Opsional: hooks supaya sesi selalu tercatat Hook SessionStart / Stop di .claude/settings.json memanggil anchoa-hook, jadi mulai/selesainya sesi tercatat walau agen lupa memanggil MCP. Contoh lengkap ada di docs/agent-integration.md.
