# Fitur Reset Password via OTP WhatsApp

Sasaran: Mengizinkan pengguna memulihkan akses akun tanpa ketergantungan email server.

## Aturan Bisnis & Keamanan

  • Panjang kode: 6 digit angka acak (CSPRNG).
  • Masa berlaku: 5 menit sejak pengiriman.
  • Rate limit: Maksimal 3 kali permintaan per nomor per jam.
  • Harness executor: Dikerjakan dengan Rust command di backend + React form.

## Kriteria Keberhasilan

  • ✓ Skema token tersimpan aman dengan Argon2.
  • ✓ E2E test Xvfb mencakup skenario input valid & kedaluwarsa.
