Pertanyaan yang sering muncul

Apakah Anchoa gratis?

Ya. Kamu hanya membayar layanan pihak ketiga yang kamu pilih sendiri, misalnya kunci API AI. Model lokal lewat Ollama tidak butuh kunci.

Data saya disimpan di mana?

Data terstruktur (tugas, jadwal, keuangan, habit) ada di proyek Supabase-mu, region Singapura. Jurnal dienkripsi dulu di perangkat. File, email, dan unduhan tetap di laptop atau HP-mu.

Apakah butuh internet?

Data terakhir tampil dari cache di perangkat, jadi app tetap bisa dibaca saat offline. Sinkron, AI cloud, dan akses file laptop dari luar rumah butuh koneksi.

Kenapa namanya Anchoa?

Anchoa adalah kata Spanyol untuk ikan teri. Teri kecil, tapi bergerak dalam kawanan besar yang rapi; itu gambaran yang kami mau untuk urusan harianmu.

Bisa dipakai di Windows, macOS, atau Ubuntu?

Belum. Saat ini Anchoa baru tersedia untuk Fedora (.rpm). Distro Linux lain menyusul lewat Flatpak, lalu Android, Windows, dan macOS dari codebase Tauri yang sama. Urutannya ada di rute platform pada bagian Unduh.

Avatar-nya bisa diganti?

Bisa. Anchoa memakai Cubism SDK dari Live2D; kamu bisa mengimpor model .model3.json milikmu sendiri. Model contoh dari Live2D hanya untuk uji, sesuai lisensinya.

Yang berenang di halaman ini

Diurutkan dari permukaan. Ikan lentera biasanya tinggal lebih dalam dan naik ke atas saat malam.

  • TongkolEuthynnus affinisPemangsa teri. Saat ia datang, kawanan merapat jadi bola umpan.
  • Pari manta karangMobula alfrediMeluncur pelan di perairan tengah sambil menyaring plankton.
